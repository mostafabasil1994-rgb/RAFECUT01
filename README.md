# RAFECUT

موقع واجهة أمامية لمنصة **RAFECUT**: منصة متكاملة لخدمات الإنتاج في **الموصل** تخدم صنّاع الأفلام والإعلانات. الأسعار بالدولار الأمريكي.

صفحة واحدة بالعربية (RTL) والإنجليزية (LTR) بتصميم سينمائي داكن ولون ذهبي، وتعمل على الجوال وسطح المكتب.

**اللغة:** زر `EN` / `ع` في الشريط العلوي يبدّل اللغة ويتذكّر اختيارك. يمكن أيضًا فتح الموقع بالإنجليزية مباشرة عبر `?lang=en`.

## الأقسام
1. **الرئيسية**: الواجهة الأولى، نبذة عن المنصة، بطاقات الخدمات، وأداة «خطّط لمشروعك».
2. **مواقع التصوير**: فلترة حسب المدينة ونوع الموقع ونطاق السعر.
3. **المعدات والطاقم**: تبويبان، وفلترة المعدات حسب الفئة.
4. **الفنادق والمطاعم**: تبويبان، وفلترة حسب الميزانية.
5. **المونتاج وتصحيح الألوان**: الخدمات وثلاث باقات أسعار.
6. **تواصل معنا**: نموذج تواصل وبيانات الاتصال.

## التشغيل
لا يحتاج الموقع إلى أي بناء أو تثبيت. افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8000
```

## الهيكل
```
index.html        الصفحة
css/style.css     التصميم
js/data.js        البيانات التجريبية بالعربية مع حقل en للإنجليزية
js/i18n.js        نصوص الواجهة الإنجليزية ورسائل الواجهة باللغتين
js/main.js        العرض والفلاتر والتبويبات والنماذج والنافذة المنبثقة
assets/           الشعار وأيقونة الموقع
images/           صور المواقع والمعدات والفنادق (أضفها بنفسك)
```

## تعديل المحتوى
- **البيانات:** كل البيانات موجودة في `js/data.js`. عدّل الأسماء والأسعار من هناك، والنص الإنجليزي لكل عنصر في حقل `en`.
- **النصوص الثابتة:** النص العربي مكتوب في `index.html`، والإنجليزي في `js/i18n.js` بنفس المفتاح `data-i18n`.
- **الصور:** ضع صورك في مجلد `images/` بالأسماء المذكورة في `images/README.md`. أي صورة غير موجودة يظهر مكانها شكل بديل.
- **الشعار:** الشعار مرسوم بصيغة SVG في `assets/logo.svg` و`assets/logo-mark.svg`، ويتكوّن من حرف R داخل إطار عدسة الكاميرا، وساقه المائلة ترمز إلى «القص» في المونتاج.

> هذه نسخة واجهة أمامية فقط. لا توجد قاعدة بيانات ولا تسجيل دخول، ونماذج الحجز والطلب تعرض نافذة تأكيد فقط.
